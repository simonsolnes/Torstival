Download **torstival.apk** from Assets below and open it on an Android phone.
Allow installation from your browser or file manager if Android asks. Requires
Android 7.0 or later. No Expo Go, account, development server, or internet needed
to run the app.

- Set an interval from 1 to 3600 seconds, then Start or Stop on one screen.
- Watch the live countdown to the next screen flash.
- Enable vibration and rear flashlight pulses independently.
- On Android, pulses continue in the background with a notification Stop button.
  The screen itself flashes only while the app is visible.

Flashlight access requests Camera permission; no photos or videos are recorded.
Battery restrictions, Doze, camera availability and device settings can delay or
prevent background pulses. Force-stop or reboot ends the session.

Built locally as a signed, standalone APK. TypeScript checks, 7 JavaScript tests,
and 16 native Android tests passed. iOS simulator and unsigned device builds also
passed; iOS pulses stop when leaving the app, and no installable iOS package is
included. Physical flashlight, vibration and locked-screen behavior still need
verification on an Android phone.
