Download **torstival.apk** from Assets below. It installs over v1.1.0 using the
same signing key. Requires Android 7.0 or later.

- Removed decorative text and simplified the screen.
- Added minute and second pickers, defaulting to **5:00**. Seconds-only intervals
  work too, from **0:01**; the maximum is **60:00**.
- Countdown now displays minutes and seconds.
- Added a **Sound** toggle for a short beep on every interval, including in the
  Android background service. Uses media volume.
- Increased vibration to **450 ms at maximum supported amplitude** on Android.
  Actual strength depends on the phone.

Stop cancels the timer and all feedback. Android battery restrictions and device
settings can still affect background pulses. Physical sound, flashlight and
vibration output need verification on a real phone.

iOS also gets the pickers, beep and stronger haptics. iOS runs in the foreground
only and respects the silent switch; no installable iOS package is included.
